# 护眼之道

[English](README.md) · 简体中文

护眼之道（GazeEase）是一款安静驻留在 macOS 菜单栏的休息提醒工具，帮你适时停一停，也看清今天的用眼节奏。

![护眼之道地平线主题的全屏休息提醒](docs/images/rest-horizon.png)

## 按你的节奏，休息一下

- **时长自己定**：默认有效使用 20 分钟后，提醒休息 20 秒，两项时长都可调整。
- **提醒有轻重**：系统通知、顶部弹窗、全屏提醒，三种方式自由选择。
- **九款自然皮肤**：全屏、弹窗与面板风格统一，也可定时随机更换。
- **今天一眼看懂**：查看疲劳曲线、峰值与超负荷时长，数据只在本机处理和保存。

<summary>想了解具体的提醒和休息规则？</summary>

- 疲劳度是基于使用时长的估算，不是医学测量。达到设定使用时长对应 100%，继续使用可以超过 100%。
- 选择“暂不休息”后，每达到新的 100% 整数倍会再提醒。部分休息降到 100% 以下后，提醒暂停，重新达到 100% 时再提醒。
- 开始休息会覆盖所有显示器；操作会中断倒计时，但保留已恢复的疲劳度。连续完成一次休息后，疲劳归零。
- 锁屏或睡眠可以计入休息；长时间无操作自动休息是可选功能，默认不会仅因静止就判定休息。
- 调整使用时长会按已累计的有效使用量重算疲劳；设置与疲劳状态会在重启后保留。

</details>

## 隐私

“输入监控”只用于判断是否操作电脑、是否中断休息，不记录你输入了什么。App 不申请“屏幕录制”，不保存屏幕内容或按键内容，也不发送遥测数据；处理和存储都在本机完成。[查看隐私说明 →](PRIVACY.zh-CN.md)

## 从源码体验

Version `1.1.0`、Build `39` **仅公开源码，暂不提供通用安装包**。现有开发包未使用 Developer ID 签名、未经过 Apple 公证，不是面向所有人的公开安装器。

自行运行需要 macOS 14+ 和 Xcode 16+。打开 `EyeProtection.xcodeproj`，选择自己的 Team 与独立 Bundle Identifier，构建后按提示授予“输入监控”权限。[开发环境与测试说明 →](CONTRIBUTING.zh-CN.md)

已有本机包请看[安装、升级与卸载](INSTALL.zh-CN.md)。为兼容原有安装，App 文件名仍为 `GazeEase.app`，中文显示名为“护眼之道”。
