护眼之道（GazeEase）熟人测试版安装说明
版本 1.1.0（Build 39）

中文显示名为“护眼之道”，英文沿用 GazeEase。App 文件名和安装包名仍使用 GazeEase，安装路径仍为 /Applications/GazeEase.app，兼容原有升级与数据。

重要说明

这是开发者直接提供的 Apple Development 签名测试版，未经 Apple 公证，不是公开发行版。
请只在确认 ZIP 由开发者本人直接发送、且 SHA-256 校验值一致时安装；请勿二次转发。

一、安装

1. 完整解压 ZIP。
2. 打开解压后的文件夹。
3. 将 GazeEase.app 拖入“应用程序（Applications）”文件夹。
4. 从“应用程序”文件夹双击护眼之道（文件名为 GazeEase.app）。

二、首次打开时被 macOS 拦截

1. 如果系统提示“无法验证开发者”或“Apple 无法检查它是否包含恶意软件”，先关闭提示。
2. 打开“系统设置 → 隐私与安全性”。
3. 向下滚动到“安全性”，找到刚刚被阻止的护眼之道。
4. 点击“仍要打开”，输入当前 Mac 的登录密码，然后再次点击“打开”。

“仍要打开”通常只在首次尝试后的约一小时内显示。如果没有看到，请重新双击一次护眼之道，再返回该页面。

系统提示、权限或登录项列表可能因旧缓存仍显示 GazeEase，它与护眼之道是同一个 App。

如果系统提示 App“已损坏”或“会损害你的电脑”，请不要继续。删除该副本，并把完整提示截图发给开发者。

Apple 官方说明：
https://support.apple.com/guide/mac-help/open-an-app-by-overriding-security-settings-mh40617/mac

三、开启输入监控

护眼之道需要“输入监控”权限来判断电脑是否正在使用，以及休息是否被操作中断。

1. 按 App 内的新手引导点击“去授权”，或打开“系统设置 → 隐私与安全性 → 输入监控”。
2. 开启护眼之道。
3. 完全退出护眼之道，再从“应用程序”重新打开。

通常不需要重启电脑。如果重新打开后仍显示未授权，可先关闭系统中的旧护眼之道（或 GazeEase）开关，再重新授权；仍不生效时再重启 Mac 一次。

护眼之道不需要“屏幕录制”权限。它不会保存按键内容、鼠标坐标或屏幕画面，分析数据只保存在本机。

四、升级

1. 退出正在运行的护眼之道。
2. 解压开发者发送的新版本。
3. 将新的 GazeEase.app 拖入“应用程序”，系统询问时选择“替换”。
4. 重新打开护眼之道。

偏好、疲劳历史和皮肤设置通常会保留。若 macOS 再次要求“仍要打开”或输入监控权限，请重复上述步骤。

五、卸载

1. 在护眼之道设置中关闭“登录时启动”。
2. 退出护眼之道。
3. 将“应用程序”中的 GazeEase.app 移到废纸篓。
4. 如有需要，在“系统设置 → 通用 → 登录项”确认没有残留项目，并在“隐私与安全性 → 输入监控”中关闭护眼之道。

直接卸载不会自动清除偏好和疲劳历史。如希望删除分析记录，请在卸载前使用 App 内的“清除所有分析数据”。

已知限制

- 每台 Mac 都可能需要手动确认“仍要打开”，后续版本也可能再次要求确认。
- 公司或学校管理的 Mac 可能禁止“仍要打开”或输入监控权限。
- 当前没有自动更新，升级需要手动替换 App。
- 开发签名到期或被撤销后，可能需要开发者提供新包。
- 需要 macOS 14 或更高版本；支持 Apple 芯片和 Intel Mac。
